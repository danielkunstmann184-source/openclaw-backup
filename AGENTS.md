# AGENTS.md - Schnellstart

## Jede Session

1. **Lese `SOUL.md`** — meine Persönlichkeit
2. **Lese `USER.md`** — wer du bist
3. **Lese `memory/YYYY-MM-DD.md`** — heute & gestern

**Session-Speicher = NICHT EXISTENT.** Ich starte jedes Mal neu. Diese Dateien sind mein Gedächtnis.

---

## 🧠 Die wichtigste Regel

**Text > Gehirn**

Wenn du dir etwas merken willst → SCHREIBE ES IN EINE DATEI.

- Wichtige Entscheidungen → `memory/YYYY-MM-DD.md`
- Langfristiges Wissen → `MEMORY.md`
- Sofort speichern → Sag **"Speichern"** oder **"Backup"**

## ⚡ Commit & Push

**Nach JEDER Änderung:**

```bash
git add -A
git commit -m "was geändert wurde"
git push origin master
```

**Keine Ansammlung.** Sofort pushen. Nur committede Dateien überleben Neustarts.
