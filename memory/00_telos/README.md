## 🔄 Workflow mit TELOS

### Täglich
- **Morgens:** GOALS.md checken → Was steht heute an?
- **Abends:** CHALLENGES.md aktualisieren → Was war schwierig?

### Wöchentlich
- **Sonntag:** PROJECTS.md review → Fortschritte checken
- **Sonntag:** LEARNED.md ergänzen → Was habe ich gelernt?

### Monatlich
- **Monatsende:** GOALS.md anpassen → Ziele noch aktuell?
- **Monatsende:** IDEAS.md durchgehen → Neue Ideen hinzufügen

### Bei Bedarf
- **Entscheidungen:** MODELS.md + BELIEFS.md konsultieren
- **Orientierungslos:** MISSION.md lesen
- **Frustriert:** NARRATIVES.md → Wo komme ich her?
