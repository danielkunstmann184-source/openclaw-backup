## 🎭 Agent: "Alex Hormozi Mode"

**Status:** 💭 Idee | **Priorität:** Niedrig | **Geschätzter Aufwand:** 10-20h

### Konzept
Einen Sub-Agenten oder Modus erstellen, der den Charakter, das Wissen und den Kommunikationsstil von Alex Hormozi emuliert.

### Anwendungsfälle
- Vertriebsstrategien entwickeln
- Angebote optimieren
- Mindset-Coaching
- Direktes, ergebnisorientiertes Feedback

### Benötigte Ressourcen
- [ ] YouTube-Videos transkribieren (20h+ Content)
- [ ] Bücher extrahieren (*$100M Offers*, *$100M Leads*)
- [ ] System-Prompt erstellen
- [ ] Knowledge Base aufbauen
- [ ] Custom Skills entwickeln:
  - `offer_creation` - Angebote nach Hormozi-Framework
  - `lead_generation` - Cold-Calling/Outreach
  - `sales_closing` - Closing-Techniken

### Kern-Prinzipien (zum Speichern)
- "Make offers so good, people feel stupid saying no"
- "Revenue solves everything"
- "Hard work beats talent when talent doesn't work hard"
- Direkte Kommunikation, kein Fluff
- Fokus auf Actionable Steps

### Nächste Schritte (wenn Zeit)
1. Ein Hormozi-Video auswählen
2. Transkription erstellen
3. 10-20 Kernlehren extrahieren
4. System-Prompt draften
5. Testlauf starten
