## 📋 Phasenplan

### Phase 1: Sprachsteuerung (Einstieg)
- [ ] Raspberry Pi 4/5 besorgen (4GB RAM)
- [ ] OpenClaw auf Pi installieren
- [ ] USB-Mikrofon anschließen
- [ ] Erste Tests: Sprache → Text → Aktion

**Ziel:** "Licht an" → Roboter schaltet LED

### Phase 2: Kamera-Integration
- [ ] USB-Kamera anschließen
- [ ] Bilder aufnehmen bei Sprachbefehl
- [ ] Bildanalyse über OpenClaw

**Ziel:** "Was siehst du?" → Beschreibung der Umgebung

### Phase 3: Aktorik
- [ ] GPIO-Steuerung (LEDs, Relais)
- [ ] Einfache Bewegung (Servos/Motoren)
- [ ] Steckdosen schalten

**Ziel:** Physische Aktionen im Haus

### Phase 4: Mobilität (später)
- [ ] Fahrgestell/Räder
- [ ] Autonomes Fahren (einfach)
- [ ] Karten erstellen
